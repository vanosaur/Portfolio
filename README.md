# Vani Rudra | Portfolio 🚀

Welcome to my personal portfolio! This is a modern, high-performance **Single Page Application (SPA)** built with **Next.js 15**, **Tailwind CSS**, and **Framer Motion**.

## ✨ Features

- **Premium UI/UX**: Custom-designed with glassmorphism, vibrant gradients, and a "Cosmic Glass" aesthetic.
- **Micro-Animations**: Staggered scroll reveals, parallax grids, and silky-smooth section transitions.
- **Dynamic Backgrounds**: Fixed video backgrounds with scroll-linked opacity masks.
- **Interactive Sketch Space**: A high-end art gallery with an integrated lightbox and spring-physics animations.
- **Universal Flow**: Unified typography and consistent design tokens across all sections.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: Shadows Into Light (Signature), Poppins (Headers), Montserrat (Body)

## 🚀 Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📁 Project Structure

- `src/app`: Page layout and global styles.
- `src/components`: Modular components for each section (Home, About, Art, Contact).
- `public/PHOTOS`: Optimized image assets.
- `public/videos`: Background video and project previews.
